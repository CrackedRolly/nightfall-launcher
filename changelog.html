New in 0.3.3

  • Newest Java 21 (Temurin) and a fuller starting memory allocation, for smoother FPS.
  • Your FPS cap is never overwritten; a fairer Compare FPS and a CurseForge-identical test launch.
  • Turn off all HUD with one switch or a key, and get exactly what you had back.
  • New instances start clean: transfer all your settings from another instance, or start fresh.
  • Fixed: Customize no longer changes your GUI scale.
