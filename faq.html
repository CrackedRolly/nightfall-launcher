§FAQ

Questions, answered.

Can't find yours? Ask on Discord. Game crashed? Try crash help first.

Is Nightfall free?
Yes. Nightfall is free, with no ads and no paid tiers. You still need to own Minecraft: Java Edition to play online.
Windows says "Windows protected your PC". Is it safe?
The installer isn't code-signed yet, so SmartScreen warns about every new app. Click More info, then Run anyway. Only download Nightfall from this website or the official GitHub releases.
Why can't I sign in with Microsoft yet?
Sign-in is built, but Minecraft's services only accept a new launcher after Mojang approves it. Everything works as soon as approval comes in.
Does it work on macOS or Linux?
Linux, yes: there's an AppImage (x86_64) on the download page, though Windows gets the most testing. There's no macOS build yet.
How do updates work?
Nightfall checks when it starts and every few hours, downloads quietly and shows Update ready with a Restart button. On 0.1.0, install the latest version once by hand.
Does Nightfall have Forge?
Yes. Fabric, Quilt, Forge and NeoForge all work, plus vanilla, snapshots, old alpha and beta versions and LiteLoader. OptiFine works on Forge.
My game crashed. What now?
Open crash help and paste your log, or use /crash in our Discord. Both match it against over 100 known crashes and tell you the fix.
Is Nightfall official?
No. Nightfall is an independent project. It isn't an official Minecraft product and isn't approved by or associated with Mojang or Microsoft.
What does Nightfall collect?
Almost nothing. Your sign-in happens on Microsoft's own page and tokens stay encrypted on your PC. See the privacy policy.
Will Nightfall give me more FPS?
Nightfall is built for max FPS: a performance preset, tuned Java flags, and the launcher pauses while you play. Your FPS still depends mostly on your PC, game settings and mods, so we don't promise a number. Run Performance check (Instance → Options) to see which graphics card and memory the game will use.
Who can see my emotes and Nightfall badge?
Only other Nightfall players, and only once the optional Nightfall online service launches. It's off by default and only shares your Minecraft player ID. Until then, emotes play just for you.
Can friends join my local server over the internet?
The local server is for your PC and home network (LAN). Friends outside your home can't join it without a server setup of your own.
§Troubleshooting

Troubleshooting

Fixes for the problems people hit most, in order. Still stuck? Paste your log into Crash help or ask on Discord.

The game won't start or closes right away
Open the instance's console in Nightfall and paste the last lines into Crash help. It names the most likely cause. Usually it's a mod made for a different Minecraft version or loader, or a missing dependency.
My FPS is lower than in another launcher
Run Performance check on the instance. It shows the graphics card, Java and memory the game will use. On a laptop, make sure it shows your dedicated GPU. Then compare the in-game video settings: render distance and VSync matter most. If it still looks wrong, post the screenshot on Discord.
Windows says the installer isn't safe
The installer isn't code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway. You can check its SHA-256 on the download page first.
My antivirus blocked a file
Some antivirus tools flag new apps that aren't signed. Download only from this site or our GitHub releases and check the SHA-256. If it matches, you can add an exception.
The screen is black or white when the game opens
Update your graphics driver from your GPU maker's website. If you use shaders, try the instance without them. On a laptop, check which GPU Performance check shows.
My keybinds or settings changed
Nightfall shares keybinds, controls and audio between instances. An instance can keep its own settings instead: turn that on in the instance's settings. FPS options are never shared.
Microsoft sign-in doesn't work yet
Sign-in is built into the launcher, but Mojang has to approve Nightfall before it can be used. We'll announce it on Discord as soon as it's approved.
