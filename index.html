// what it does

Microsoft sign-in
Official Microsoft OAuth login. Your password never touches the launcher, and tokens stay on your PC.
Fabric & Forge
Install a loader for any supported version in one click, each in its own instance.
Modrinth browsing
Search, install and update mods, resource packs and modpacks through the Modrinth API, with dependencies resolved for you.
Performance profile
A ready-made set: Sodium Lithium FerriteCore EntityCulling ImmediatelyFast ModernFix.
Java & memory
Sensible RAM allocation and JVM flags chosen for your machine, with a manual override if you know what you're doing.
Recommendations
Curated bundles for PvP, Performance, Survival and Shaders. Install a whole setup instead of hunting for twenty mods.
Toggle mods in-game
Turn mods off from inside the game and hit Restart. Minecraft closes, relaunches with the new set and lands on the title screen.
