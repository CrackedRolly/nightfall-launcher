# Nightfall website and public releases

Work only on feature/nightfall-next-update. Do not change or merge into main or
master, deploy Pages/services, or publish a public release without explicit owner
approval. Do not request secrets in chat or modify credentials.

This repository is a plain HTML/CSS/JS static website, generated by
`tools/build-site.py` from tools/i18n and tools/i18n/v3 (10 languages).
Browser JS is in assets; data/crash-kb.json powers crash help. Legal translations
are in i18n/legal. The private sibling nightfall-launcher-app repository contains
Electron, companion builds, services and draft-release orchestration; read its
AGENTS.md and docs/CI-CD.md when changing app/release behavior. Releases are hosted
here, while release notes record both app and website SHAs.

Run `python3 tools/check-site.py` for isolated, deterministic offline generation,
translation coverage, all 10 pages and local asset/link checks. No pip dependencies
are needed. `NF_SITE_OFFLINE=1 python3 tools/build-site.py` builds without external
services. Normal generation uses bounded HTTPS fetches for current public release
and Modrinth fallbacks; failure does not authorize publishing stale data. For
preview use `python3 -m http.server 8765` (loopback in managed environments).
Keep every English key translated in all locales; do not overwrite legal text.
Generated pages and i18n output must stay consistent with sources. Check the
working tree before/after generation and preserve user edits/assets.

Use .github/workflows/ci.yml for pushes/PRs/manual checks; it never deploys.
Do not disable secret scanning or deletion guards to make checks green. Changes
to source and generated output must be reviewed together. No dependency downloads
without version/checksum validation. Never force push or replace release assets.
A draft is reviewable preparation only; publication requires explicit owner
approval and all app, service, companion, native packaging and website gates.
