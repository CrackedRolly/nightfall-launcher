# Nightfall Launcher website
Plain HTML/CSS, no build step. Open `index.html` in a browser, or run `python3 -m http.server` here and visit http://localhost:8000.

## Deploy
1. GitHub Pages: push this folder to a repo `nightfall-launcher`, then Settings → Pages → Branch `main` / root.
2. URL: https://crackedrolly.github.io/nightfall-launcher/
3. Netlify: drag this folder onto app.netlify.com/drop.
4. Vercel: `npx vercel` in this folder.
5. Azure Branding: Home `/`, Privacy `/privacy.html`, Terms `/terms.html`.
