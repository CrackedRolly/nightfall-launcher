# Nightfall Launcher website (v3 design)
Plain HTML/CSS/JS, no framework. Pages are generated by `tools/build-site.py`:
index, features, download, modpacks, changelog, roadmap, faq, crash-help, privacy, terms.

    python3 tools/build-site.py      # rebuild every page + i18n/*.json
    python3 -m http.server 8765      # preview at http://127.0.0.1:8765/

- Text: English in `tools/i18n/en.json` + `tools/i18n/v3/en.json`; other languages in the same folders. Every key must exist in all 10 languages.
- Terms/Privacy translations: `i18n/legal/<lang>.json` (unchanged by the build).
- Live data in the browser: latest GitHub release (version, download links, sizes, SHA-256), all releases (changelog), Discord invite counts, Modrinth pack stats.
- 0.3.0 screenshots: drop `home.webp`, `guide.webp`, `friends.webp` (1440x900) into `assets/shots/030/` and rebuild; the placeholders are replaced automatically.
- Meteors: `assets/meteors.js` (static star layer, ~12 fps when idle, stops when the tab is hidden, static under reduced motion).
