Crash help

114 · Known Minecraft: Java Edition crashes and launch errors, with fixes ranked by what works most often. The Nightfall launcher uses the same list to explain crashes automatically. Each error has its own link you can share.

114 errors · Error details are in English for now.

MemoryOut of memory (Java heap space)#

The game used all the RAM it was given. Big modpacks, high render distance and shaders are the usual reasons.

  1. Raise this instance’s memory by 2 GB (most modpacks want 4–8 GB).
  2. Lower render distance and turn off shaders, then try again.
  3. Remove or update memory-heavy mods; add FerriteCore and ModernFix if you use Fabric/Forge.
  4. Close browsers and other games while playing.

Matches: java\.lang\.OutOfMemoryError: Java heap space · OutOfMemoryError(?!: (Metaspace|unable to create|Direct buffer))

MemoryOut of memory (Metaspace)#

Java ran out of space for class data, which happens with very large modpacks or a too-small MaxMetaspaceSize flag.

  1. Remove any -XX:MaxMetaspaceSize flag from the extra JVM arguments.
  2. Raise the instance memory by 2 GB.
  3. Use the Java version Nightfall picks automatically.

Matches: OutOfMemoryError: Metaspace

MemoryOut of direct buffer memory#

Native (off-heap) memory ran out, usually from huge texture packs, shaders or a 32-bit Java.

  1. Use a smaller resource pack or turn off shaders.
  2. Make sure you use 64-bit Java (clear the custom Java path).
  3. Raise memory by 2 GB.

Matches: OutOfMemoryError: Direct buffer memory

MemoryUnable to create native thread#

The system refused to create more threads, often because the PC itself is out of memory or a mod leaks threads.

  1. Close other programs and try again.
  2. Lower the instance memory if it is more than half your PC’s RAM.
  3. Update or remove the mod named in the stack trace.

Matches: OutOfMemoryError: unable to create (new )?native thread

MemoryCould not reserve enough space for object heap#

Java could not get the RAM you set. Either the value is larger than your free memory, or a 32-bit Java is in use (max ~1.5 GB).

  1. Lower the memory slider (keep at least 2 GB free for Windows).
  2. Clear the custom Java path so Nightfall uses its own 64-bit Java.
  3. Remove -Xmx/-Xms from the extra JVM arguments; the slider already sets them.

Matches: Could not reserve enough space for (\d+KB )?object heap · Invalid maximum heap size · Invalid initial heap size

JavaCould not create the Java Virtual Machine#

Java refused to start, nearly always because of a wrong flag in the extra JVM arguments or a memory value it cannot reserve.

  1. Clear the extra JVM arguments.
  2. Lower the memory slider.
  3. Clear the custom Java path.

Matches: Error: Could not create the Java Virtual Machine · Unrecognized (VM )?option · Error occurred during initialization of VM

MemoryGC overhead limit exceeded#

Java spent almost all its time cleaning memory, a sign the game is about to run out of RAM.

  1. Raise memory by 2 GB.
  2. Lower render distance/simulation distance.
  3. Remove heavy mods or resource packs.

Matches: GC overhead limit exceeded

MemoryToo much RAM allocated (stutters / freezes)#

Giving Minecraft nearly all your RAM starves Windows and causes stutters or crashes. More is not always better.

  1. Set memory to about half of your PC’s RAM, and no more than 8–10 GB for most packs.
  2. Use the recommended value on the memory slider.

Matches: Allocated:\s*\d+%.*\b(9\d|100)%

JavaJava is too old (UnsupportedClassVersionError)#

The game or a mod needs a newer Java than the one used. Minecraft 1.17 needs Java 16+, 1.18–1.20.4 need Java 17, 1.20.5+ needs Java 21.

  1. Clear the custom Java path so Nightfall downloads the correct Java automatically.
  2. If you must use your own Java, install Java 21 (for 1.20.5+) or 17 (1.18–1.20.4).

Matches: UnsupportedClassVersionError · Unsupported class file major version · has been compiled by a more recent version of the Java Runtime

JavaJava is too new for this version#

Old Minecraft (1.16 and older) and old Forge need Java 8. Running them on Java 17/21 breaks the class loader.

  1. Clear the custom Java path so Nightfall uses Java 8 for this version.
  2. For Forge 1.12.2 and older, Java 8 is required.

Matches: Unsupported Java detected · java\.lang\.ClassCastException: class jdk\.internal\.loader\.ClassLoaders\$AppClassLoader cannot be cast to class java\.net\.URLClassLoader · Unable to make field .* accessible: module java\.base does not "opens

Java32-bit Java in use#

32-bit Java can only use about 1.5 GB of RAM and is much slower.

  1. Clear the custom Java path (Nightfall downloads 64-bit Java).
  2. Uninstall old 32-bit Java from Windows.

Matches: Java HotSpot\(TM\) Client VM · os\.arch:?\s*x86\b · 32-bit Java

JavaJava executable not found#

The Java path in settings points to a file that does not exist (Java was uninstalled or moved).

  1. Clear the custom Java path; Nightfall downloads Java automatically.
  2. Or pick the java.exe inside your Java’s bin folder.

Matches: (java|javaw)(\.exe)?["\']?: (No such file|not found) · Cannot run program ".*java(w)?(\.exe)?" · spawn .*java(w)?(\.exe)? ENOENT

JavaJava runtime is broken or incomplete#

The Java installation is incomplete (interrupted download, antivirus removed a file) or the classpath is broken.

  1. Remove the Java runtime in Settings → Java; it re-downloads on next launch.
  2. Repair the instance.
  3. Add the Nightfall folder to your antivirus exclusions.

Matches: Error: could not find (libjava|java\.dll) · Error opening zip file or JAR manifest missing · Error: Could not find or load main class

JavaJava module access error (add-opens)#

An old mod uses Java internals that newer Java blocks.

  1. Update the mod named in the error.
  2. Use the Java version Nightfall picks for this Minecraft version.

Matches: InaccessibleObjectException · module .* does not "?opens · IllegalAccessError: class .* \(in unnamed module

Mods & loadersFabric: mod requires another mod#

A Fabric/Quilt mod needs a library mod (often Fabric API, Cloth Config, Architectury) or a specific version of it.

  1. Read the first "requires" line: it names the missing mod and version.
  2. Install the missing mod from Browse (Fabric API is the most common).
  3. Or disable the mod that needs it.
  4. Use the Updates tab to bring all mods to matching versions.

Matches: Mod resolution encountered an incompatible mod set · requires (any version|version [^\s]+) of (mod )?[\'"]?[\w-]+ · Unmet dependency listing

Mods & loadersFabric API is missing#

Almost every Fabric mod needs Fabric API, and it is not installed.

  1. Install Fabric API from Browse (Nightfall picks the version that matches).

Matches: requires (any version|version .*) of (mod )?[\'"]?fabric(-api)?[\'"]? · fabric-api.*which is missing

Mods & loadersFabric: incompatible mods#

Two mods declare that they cannot run together (for example OptiFine/OptiFabric with Sodium).

  1. Disable one of the two mods named in the log.
  2. Use Sodium + Iris instead of OptiFine on Fabric.

Matches: is incompatible with · Incompatible mods? found · breaks .* which is present

Mods & loadersMod is for a different Minecraft version#

A mod was made for another Minecraft version.

  1. Download the build of that mod for your exact Minecraft version (Browse filters this automatically).
  2. Or remove the mod.

Matches: requires (version )?.*of minecraft · Minecraft .* is not supported · Mod .* only supports Minecraft

Mods & loadersMod for the wrong loader#

A Forge mod was dropped into a Fabric instance (or the other way round). Each loader only runs its own mods.

  1. Remove the mod and download the version for your loader, or use Sinytra Connector on Forge/NeoForge if you know what you are doing.
  2. Quilt can run most Fabric mods, but not Forge mods.

Matches: is a Forge mod.*Fabric|is a Fabric mod.*Forge · Found a Forge mod in a Fabric|Found Fabric mod.*Forge · mods\.toml.*not found.*fabric\.mod\.json|fabric\.mod\.json.*NeoForge

Mods & loadersDuplicate mods#

The same mod is installed twice, usually an old and a new version side by side.

  1. Open the Content tab and remove the older copy.
  2. Check the mods folder for "(1).jar" style copies.

Matches: Duplicate mods? found · DuplicateModsFoundException · found duplicate mod

Mods & loadersMixin apply failed#

A mod tried to patch Minecraft code that changed or that another mod already patched. The log names the mod.

  1. Look for "for mod <name>" in the error and update or disable that mod.
  2. Update all mods (Updates tab).
  3. If it started after adding a mod, disable that one first.

Matches: Mixin apply (for mod [\w-]+ )?failed · MixinApplyError · InvalidInjectionException

Mods & loadersTwo mods patch the same code#

Two mods change the same part of the game in incompatible ways.

  1. Disable recently added mods one at a time to find the pair.
  2. Check each mod page for known incompatibilities.

Matches: @Overwrite conflict · Mixin .* conflicts with · mixin target .* was not found

Mods & loadersClass not found / method missing#

A mod was built against a different Minecraft, loader or library version, or a library mod is missing.

  1. Check the class name in the error: it usually contains the mod’s package name.
  2. Update that mod and its libraries, or remove it.
  3. Make sure loader and Fabric API are up to date.

Matches: ClassNotFoundException · NoClassDefFoundError · NoSuchMethodError

Mods & loadersForge/NeoForge: missing or unsupported mods#

Forge/NeoForge stopped because a mod is missing a dependency or the versions do not match.

  1. Read the "Mod X requires Y" line and install Y in the version it asks for.
  2. Make sure the Forge/NeoForge version is new enough for your mods.

Matches: Missing or unsupported mandatory dependencies · Mod [\w-]+ requires [\w-]+ · Failure message: Mod .* requires

Mods & loadersForge: mods have errors (FML error screen)#

One or more mods crashed while loading. The mod is named in "Caught exception from".

  1. Find "Caught exception from <mod>" and update or remove that mod.
  2. Check that the mod matches your Minecraft and Forge version.

Matches: Mod loading has failed · LoadingFailedException · fml\.modloading\.(brokenfile|errorduringevent)

Mods & loadersForge mods in a NeoForge instance (or reverse)#

NeoForge 1.20.2+ no longer loads Forge mods (and Forge does not load NeoForge mods).

  1. Download the NeoForge version of the mod.
  2. Or use a Forge instance for Forge-only mods.

Matches: neoforge.*mods\.toml.*forge|requires forge.*neoforge · Mod .* requires forge · META-INF/neoforge\.mods\.toml

Mods & loadersQuilt: mod loading failed#

Quilt could not load a mod, usually a missing dependency or a Fabric mod that needs Fabric-only internals.

  1. Install Quilted Fabric API (QFAPI) instead of plain Fabric API.
  2. Update or remove the mod named in the error.

Matches: org\.quiltmc\.loader\.impl\.FormattedException · Quilt Loader.*(could not|failed) · quilt\.mod\.json.*(invalid|error)

Mods & loadersLoader is too old for a mod#

A mod needs a newer Fabric/Quilt/Forge loader than the one this instance uses.

  1. Edit the instance and pick the newest loader version.

Matches: requires (version )?[>=\s]*[\d.]+ (or later )?of (mod )?(fabricloader|fabric-loader|quilt_loader|forge|neoforge) · Fabric Loader .* is outdated · requires fabricloader

Mods & loadersBroken or corrupted mod file#

A mod .jar is damaged (incomplete download, or it is not really a jar).

  1. Remove the mod named in the log and reinstall it from Browse.
  2. Never download mods from re-upload sites; use Modrinth or CurseForge.

Matches: zip END header not found · ZipException · invalid (LOC|CEN) header

Mods & loadersCorrupted mod config#

A mod’s config file is broken (often after a crash or a manual edit).

  1. Delete the config file named in the log from the instance’s config folder; the mod recreates it.

Matches: (Failed to load|Error loading|Invalid) config(uration)? (file|for) · ParsingException.*\.(toml|json5?) · com\.electronwill\.nightconfig.*ParsingException

Mods & loadersOptiFine with Fabric/Sodium#

OptiFine does not work well with modern mods. On Fabric it conflicts with Sodium/Iris and many others.

  1. Remove OptiFine/OptiFabric and use Sodium + Iris (Recommendations → Performance) for the same benefits.

Matches: optifabric · OptiFine.*(Sodium|Iris)|(Sodium|Iris).*OptiFine · net\.optifine.*Mixin

Mods & loadersOptiFine incompatible with Forge mods#

OptiFine conflicts with Embeddium/Rubidium/Oculus and many Forge mods, and must match the exact Forge version.

  1. Remove OptiFine and use Embeddium + Oculus instead.
  2. If you keep it, use the OptiFine build that matches your Forge version exactly.

Matches: optifine.*(Rubidium|Embeddium|Oculus) · OptiFine.*incompatible|incompatible.*OptiFine · net\.optifine.*Forge

Mods & loadersSodium/Iris version mismatch#

Iris needs one specific Sodium version.

  1. Update Sodium and Iris together from the Updates tab.

Matches: Iris.*requires.*sodium · sodium.*(incompatible|unsupported) · Incompatible Sodium version

Graphics & driversShader pack failed to compile#

The shader pack does not support your GPU, driver or Iris version.

  1. Turn shaders off (press O in game with Iris) or choose another pack.
  2. Update your GPU driver.
  3. Update Iris.

Matches: Failed to (compile|link) (shader|program) · shader.*compil(e|ation) error · Iris.*Failed to load shader pack

Graphics & driversShaders ran out of GPU memory#

Shaders plus high resolution packs needed more video memory than your GPU has.

  1. Use a lighter shader profile or turn shaders off.
  2. Lower render distance and resource pack resolution.

Matches: GL_OUT_OF_MEMORY · out of video memory · VK_ERROR_OUT_OF_DEVICE_MEMORY

Mods & loadersRendering mod conflict#

Two rendering mods both try to replace the same renderer.

  1. Keep only one renderer mod (Sodium on Fabric, Embeddium on Forge).

Matches: (EntityCulling|Embeddium|Rubidium|Sodium).*(conflict|incompatible) · IncompatibleModException

WorldsTicking entity crash#

An entity (mob, item, minecart) in the world causes a crash every time it updates, usually from a mod bug.

  1. Update the mod that adds the entity (see "Entity Type" in the report).
  2. Back up the world, then remove the entity with a tool like MCA Selector or by setting "removeErroringEntities" in the mod’s config (Forge).
  3. Restore an older backup of the world.

Matches: Ticking entity · Entity being ticked

WorldsTicking block entity crash#

A block entity (chest, machine, furnace) crashes when it updates.

  1. Update the mod that adds the block (see "Block type" in the report).
  2. On Forge, set removeErroringBlockEntities=true in config/forge-common.toml, play once, then turn it off.
  3. Restore a world backup.

Matches: Ticking block entity · Block entity being ticked

WorldsException ticking world#

Something in the world crashed the internal server (chunk, entity or a mod’s world logic).

  1. Update all mods.
  2. Try the world with recently added mods disabled.
  3. Restore a backup from the Worlds tab.

Matches: Exception ticking world · Exception in server tick loop

WorldsWorld or chunk is corrupted#

A world file was damaged (power loss, crash during save, or a disk issue).

  1. Restore a backup from the Worlds tab.
  2. Rename level.dat_old to level.dat inside the world folder.
  3. Use MCA Selector to delete only the broken chunks.

Matches: Couldn\'?t load chunk · Chunk file at .* is in the wrong location · Failed to read level\.dat

WorldsWorld saved in a newer version#

Opening a world in an older Minecraft version than it was last played in can corrupt it.

  1. Open the world in the same or a newer Minecraft version.
  2. Back it up before switching versions.

Matches: (World|Level) was saved (with|in) a newer version · Unsupported world data version · DataFixer.*newer

WorldsMissing blocks/items after removing mods#

The world contains things from a mod that is no longer installed.

  1. Reinstall the removed mod, or accept the warning knowing those blocks/items will be deleted.
  2. Back up the world first.

Matches: Missing registry entries · Unidentified mapping from registry · Registry .* is missing entries

WorldsData pack failed to load#

A data pack (in the world or from a mod) has errors.

  1. Start the world in Safe Mode from the error screen.
  2. Remove the broken data pack from the world’s datapacks folder.
  3. Update mods that add recipes or worldgen.

Matches: Failed to load datapacks · Errors in currently selected data ?packs · Couldn\'?t load data ?pack

WorldsWorld is open in another game (session.lock)#

Another Minecraft window or a backup program is using the world.

  1. Close other Minecraft windows and backup/sync tools (OneDrive) and try again.
  2. Move the instance out of OneDrive-synced folders.

Matches: session\.lock · The save is being accessed from another location · Failed to check session lock

Graphics & driversPixel format not accelerated#

Windows is using a basic display driver, or the game runs on a GPU without OpenGL support.

  1. Install the latest driver from your GPU maker (NVIDIA, AMD or Intel), not just Windows Update.
  2. On laptops, set Java (javaw.exe) to use the dedicated GPU in Windows Graphics settings.
  3. Remote Desktop sessions do not support OpenGL; play locally.

Matches: Pixel format not accelerated · WGL: The driver does not appear to support OpenGL · GLFW error 65542

Graphics & driversOpenGL version not supported (GLFW 65543)#

Minecraft 1.17+ needs OpenGL 3.2. The GPU or its driver is too old.

  1. Update the GPU driver.
  2. Very old Intel HD (2nd/3rd gen) GPUs cannot run 1.17+; play 1.16.5 or older.

Matches: GLFW error 65543 · OpenGL 3\.2 .*required · Requested OpenGL version 3\.2

Graphics & driversGLFW error 65544 / window could not be created#

The game could not open a window, usually a graphics driver or display configuration problem.

  1. Update the GPU driver.
  2. Disconnect extra monitors and try again.
  3. Turn off "Start in fullscreen" for this instance.

Matches: GLFW error 65544 · Failed to create the GLFW window · GLFW error 65537

Graphics & driversIntel graphics driver crash#

A known crash in Intel’s OpenGL driver.

  1. Install the newest Intel graphics driver from intel.com (not the laptop maker’s old one).
  2. On laptops with NVIDIA/AMD, make Java use that GPU instead.

Matches: ig\d+icd(32|64)\.dll · igxelpicd64\.dll · Intel.*(HD|UHD|Iris) Graphics.*(crash|EXCEPTION_ACCESS_VIOLATION)

Graphics & driversAMD graphics driver crash#

A crash inside AMD’s OpenGL driver. Some driver versions have OpenGL bugs.

  1. Update the AMD Adrenalin driver, or roll back one version if it started after an update.
  2. Disable AMD overlays (Radeon overlay, Anti-Lag).

Matches: atio6axx\.dll · atioglxx\.dll · amdxc64\.dll

Graphics & driversNVIDIA graphics driver crash#

A crash inside NVIDIA’s OpenGL driver, often fixed by a clean driver install.

  1. Update the NVIDIA driver (choose "Clean installation").
  2. Turn off "Threaded optimization" for javaw.exe in NVIDIA Control Panel if it persists.

Matches: nvoglv(32|64)\.dll · nvogl.*EXCEPTION · NVIDIA.*EXCEPTION_ACCESS_VIOLATION

Graphics & driversNative crash (EXCEPTION_ACCESS_VIOLATION)#

Java crashed in native code: usually a GPU driver, an overlay hooking the game, or a broken native library.

  1. Update the GPU driver.
  2. Turn off overlays: Discord, Steam, GeForce Experience, MSI Afterburner/RivaTuner, OBS game capture.
  3. Look at the "Problematic frame" line: a .dll name there points to the culprit.

Matches: EXCEPTION_ACCESS_VIOLATION · A fatal error has been detected by the Java Runtime Environment · SIGSEGV

Graphics & driversOverlay or recording software crash#

An overlay (RivaTuner, Discord, OBS, Steam, Overwolf) injected into the game and crashed it.

  1. Disable the overlay for Minecraft/javaw.exe or close that program.
  2. Update the overlay software.

Matches: RTSSHooks(64)?\.dll · DiscordHook(64)?\.dll · graphics-hook(32|64)\.dll

Graphics & driversOpenGL Error 1282#

A rendering mod or shader issued an invalid OpenGL call. Usually harmless spam, sometimes black screens.

  1. Turn shaders off to test.
  2. Update Sodium/Iris/OptiFine.
  3. Disable "Show GL errors" in video settings if it is just spam.

Matches: OpenGL Error.*1282 · GL_INVALID_OPERATION

Graphics & driversBlack or white screen on start#

The game could not create its drawing surfaces, usually a driver issue or a resource pack with huge textures.

  1. Update the GPU driver.
  2. Remove large resource packs.
  3. Turn off fullscreen and set a normal window size.

Matches: Unable to (load|create) (framebuffer|texture) · Framebuffer.*(incomplete|status) · GL_FRAMEBUFFER_UNSUPPORTED

Graphics & driversTexture atlas too large#

Too many or too large textures for your GPU’s maximum texture size (common with big modpacks + HD packs).

  1. Remove HD resource packs.
  2. Lower mipmap levels in video settings.
  3. Raise memory if it is also low.

Matches: Unable to fit: .* - size: · StitcherException · Maximum texture size

Graphics & driversLWJGL native library failed to load#

The game’s native libraries are missing, blocked, or for the wrong architecture.

  1. Repair the instance so natives are re-extracted.
  2. Add the Nightfall folder to antivirus exclusions.
  3. Clear the custom Java path (wrong 32/64-bit Java).

Matches: Failed to locate library: (lwjgl|glfw) · UnsatisfiedLinkError · Can\'?t load (IA )?32-bit \.dll on a AMD 64-bit platform

Windows & filesMissing Visual C++ runtime#

Windows is missing the Microsoft Visual C++ Redistributable needed by some natives.

  1. Install the latest "Visual C++ Redistributable x64" from Microsoft.

Matches: VCRUNTIME140(_1)?\.dll · MSVCP140\.dll · api-ms-win-crt

Windows & filesSound engine failed (OpenAL)#

No audio device, or another app has exclusive control of it. The game keeps running without sound.

  1. Plug in or enable an audio device and restart the game.
  2. Turn off "exclusive mode" for your audio device in Windows Sound settings.

Matches: Failed to open OpenAL device · OpenAL initialization failed · Error starting SoundSystem

Matches: Could not find or load main class (net\.minecraft|cpw|net\.fabricmc|org\.quiltmc|net\.neoforged) · library .* (missing|not found) · Error: Unable to initialize main class

Windows & filesAntivirus or firewall blocked the game#

Security software locked, quarantined or blocked a game file or Java.

  1. Add the Nightfall data folder and javaw.exe to your antivirus exclusions.
  2. Restore quarantined files, then repair the instance.
  3. Allow javaw.exe in Windows Firewall for multiplayer.

Matches: Access is denied · EPERM: operation not permitted · EBUSY

Windows & filesFolder path with special characters#

The game folder path contains characters some mods cannot handle (non-Latin letters, !, # or very long paths).

  1. Move the Nightfall data folder to a simple path like C:\Nightfall (Settings → Data folder).
  2. Avoid "!" and "#" in folder names.

Matches: Illegal char <.*> at index · InvalidPathException · Malformed \\uxxxx encoding

Windows & filesInstance inside OneDrive / cloud folder#

Cloud sync locks files while the game writes them, causing failed saves and crashes.

  1. Keep the Nightfall data folder outside OneDrive/Dropbox/Google Drive.

Matches: OneDrive · cloud file provider

Windows & filesDisk is full#

The drive ran out of space while downloading or saving.

  1. Free some disk space (Java + assets need about 1–2 GB per version).
  2. Delete old instances or backups you do not need.

Matches: No space left on device · There is not enough space on the disk · ENOSPC

Windows & filesFile in use by another program#

Another program (a second game window, backup tool, antivirus scan) has the file open.

  1. Close other Minecraft windows and try again.
  2. Restart the PC if it persists.

Matches: being used by another process · FileSystemException.*(in use|locked)

Windows & filesPermission denied#

Nightfall or Java cannot write to the folder.

  1. Do not run the game from Program Files; keep the data folder in your user folder.
  2. Check that the folder is not read-only.

Matches: AccessDeniedException · Permission denied · EACCES
