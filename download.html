§01Installing on Windows
  1. Run the installer you downloaded.
  2. If a blue Windows SmartScreen box appears, click More info, then Run anyway. The installer isn't code-signed yet.
  3. Open Nightfall, create an instance and press Play.

Microsoft sign-in is built in and waiting on Mojang's approval.

§02Installing on Linux
  1. Download the AppImage.
  2. Make it executable:
    chmod +x Nightfall-Launcher-*.AppImage
  3. Double-click it, or run it from a terminal.
§03SHA-256

Check your download

Compare the SHA-256 checksum with the one shown above. If they match, the file is exactly the one we published.

Windows (PowerShell)
Get-FileHash .\Nightfall-Launcher-0.3.2-win-x64.exe -Algorithm SHA256
Linux (terminal)
sha256sum Nightfall-Launcher-0.3.2-linux-x86_64.AppImage
